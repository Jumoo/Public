# Public

Public files associated with Jumoo's packages and products.

This repo serves static assets and metadata that need to be publicly accessible via raw URLs (e.g. `raw.githubusercontent.com`) — things that don't belong in a source repo or the org profile/standards repo.

## Contents

- **`marketplace/`** — [Umbraco Marketplace](https://marketplace.umbraco.com/) listing files for our packages:
  - `uSync/` — uSync, uSync.Complete
  - `tm/` — Translation Manager and its connectors
- **`img/`** — screenshots and images referenced by the marketplace listings above

More may be added here over time as other things need a public, stable home.
