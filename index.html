Jumoo — Public Assets

Public files and assets for Jumoo's packages and products.

This isn't an application — it's a static file host, served via GitHub Pages. Nothing here is meant to be browsed as a site; it exists so other things (like the Umbraco Marketplace) can link to stable, public URLs.

Contents

  • marketplace/ — Umbraco Marketplace listing files for uSync, uSync.Complete, and Translation Manager
  • img/ — screenshots referenced by the marketplace listings

Note: this site doesn't do directory browsing — files are linked to directly (e.g. /marketplace/uSync/umbraco-marketplace-usync.json), the folders above just link to the GitHub repo view.
